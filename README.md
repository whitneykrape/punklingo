# Idea
Thinking about this, rather than an app telling you how to what to learn, this will move towards an app that has setup. 

Initially, you'll say "I want to learn grammar, or sentence structure or just practice symbols (in the case of Japanese, etc.) 
"Other apps" feel very "this way or no way" where it would be nice if the app had a few different ways of approaching learning. 


## Punklingo
Yea name sucks. Probably will rename before too long. A somewhat gamified language learning webapp.

Next, create some kind of initial route and a first place for some Q and As. 

Starting off heavier than I'd like with a full Next and Tailwind install but going with the flow and will pull back at some point.

"AI" may be used for coding but not for language suggestion, checking, or other content. (Not intentially anyway.)

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).
Going to just be a giant practice list for the moment with more fun coming later. 

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
